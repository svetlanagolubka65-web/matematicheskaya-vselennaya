# Математическая Вселенная

Рабочий сайт: https://svetlanagolubka65-web.github.io/matematicheskaya-vselennaya/

Состояние на 28 сентября 2026 года:
- Главная страница `index.html` показывает 5 и 6 классы.
- `class5.html`, `class5.js`, `class5-data.js` — десять тем по математике Петерсон для 5 класса; объяснения, примеры, тренировка, тест. Прогресс хранится в браузере ученика.
- `class6.html` — космическая игра для 6 класса с миссиями и сертификатами.
- `style.css` — оформление главной и пятого класса.

Планы и ограничения:
- Кабинет учителя на новом адресе пока отсутствует. Ранее он работал в другом размещении сайта с авторизацией и серверной базой. GitHub Pages размещает статические файлы; для самостоятельного добавления заданий ученикам нужно подключить отдельное серверное сохранение и доступ учителя.
- Пока новые задания и классы добавляются изменением файлов сайта. Пользователь может прислать материалы помощнику, который обновит репозиторий.
- Нужна возможность самостоятельно добавлять задания и классы через кабинет; это отдельная будущая доработка.
